# Reporting a security vulnerability

[한국어](SECURITY.ko.md)

Report a suspected security vulnerability through [GitHub's private vulnerability reporting form](https://github.com/kodonghui/corthex/security/advisories/new). Sign in to GitHub, open this repository's **Security and quality** tab, and choose **Report a vulnerability**. The report goes privately to the repository maintainers.

Include enough information to reproduce and assess the problem:

- The affected plugin (`corthex`, `corthex-memory` or `corthex-nexus`) or the NEXUS server, and the version or commit you tested.
- What can happen, the conditions needed, and a small reproduction using synthetic data.
- Any proposed fix or workaround, if you have one.

Keep vulnerability details in the private report while working with the maintainers on a fix and disclosure. Do not put credentials, personal data, private workspace links or conversation records in a public issue, pull request or report attachment. Remove these from reproductions and logs before sharing them privately too.

CORTHEX is under active development. Include the exact version or commit so the report can be checked against the current code. Ordinary bugs and feature requests belong in the [public issue forms](https://github.com/kodonghui/corthex/issues/new/choose).
