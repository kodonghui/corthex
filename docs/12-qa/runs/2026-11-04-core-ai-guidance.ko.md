생성·재사용·종료, 운영 무키 시작과 SDK 생성 0회·AI 경로만 503, 수명 팩터리와 요청 의존성의 별도 대체, 지연된 가짜가 대기하는 동안 일반 경로 응답, 전체 기한의 취소, 기한 안의 실제 SDK 재시도·대기, 구체적 SDK 예외 매핑, 타입에 따른 완료·거절·미완료·빈 결과·잘못된 형식, 실제 프레임워크의 검증·404·405·예외 500 응답과 안전한 진단, 모델 호출 없는 유효 가짜 모드·대상·소스 확인을 검사했습니다.

별도의 잘못 바꾼 사본 셋은 기존 검사에서 예상대로 실패했습니다. 요청마다 클라이언트를 만드는 사본, SDK 재시도를 감싼 설정 기한 1초 대신 30초를 기다리는 사본, 프레임워크 기본 검증 응답을 돌려주는 사본입니다. 바꾸지 않은 원본은 통과했습니다. 실패 사본을 다른 통과 구현으로 세지 않았습니다.

## 첫 프로젝트의 설치·발견

새 임시 홈마다 로컬 후보 마켓플레이스에서 핵심 플러그인만 설치했습니다. 마켓플레이스 추가·설치·목록·새 세션 명령은 모두 종료 코드 0이었습니다. 호스트가 모델에 보낸 요청에서 진입 스킬 설명을 확인했고 설치한 스킬 아홉 파일은 후보와 같았습니다. 기존 계정 프로필은 복사하지 않았고 MEMORY 저장소도 만들지 않았습니다.

| 실제 환경 | 설치한 호스트 | 결과 |
| --- | --- | --- |
| Windows 11 네이티브 | Claude Code 2.1.310 | 설치·새 세션 발견 통과 |
| Windows 11 네이티브 | Codex CLI 0.164.0 | 설치·새 세션 발견 통과 |
| macOS 13.7.8 Intel | Claude Code 2.1.310 | 설치·새 세션 발견 통과 |

로컬 모델의 고정 응답을 사용했습니다. 실제 에이전트가 프로필을 만들거나 요구사항 체크포인트를 마친 결과가 아닙니다. 공개 GitHub 마켓플레이스 경로, 기존 등록 갱신 경로, macOS의 Codex, 독자의 전체 재현과 학습은 여기서 확인하지 않았습니다. [안내](../../first-project.ko.md)는 대화와 명시적 승인을 남겨 두며, 고정 응답으로 승인을 대신하지 않습니다. 이 명령·발견 검사를 첫 독자 실험의 성공으로 보고하면 안 됩니다.

## 한계

예제는 스트리밍·상태 저장·인증이 없으며 쓰기 도구나 실제 민감 입력도 없습니다. 로컬 검사 통과로 실제 제공자 가용성, 답변 품질, 엔드포인트 보관 정책, 보관 없음, 원격 효과 취소, 운영 성능이나 부하 도구 보정을 입증하지 않습니다. 빈 starter를 만드는 F04와 부하 도구 보정 F13은 보류를 유지합니다. 출시 태그나 실제 사용자 MEMORY 활성화는 이 작업에 포함하지 않습니다.
