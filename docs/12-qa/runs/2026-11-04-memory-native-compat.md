These are real installed host executables and real native tools/hooks, using only fixed local protocol replies. They do not assess an actual model's decisions. Synthetic consent, fake keys and disposable homes/projects/stores are used. No original account profile, real-user recording, global plugin installation or paid provider call is involved. Codex trust is bypassed only for the vetted tool/lifecycle fixtures; the trust-update fixture has no hook-trust bypass.

The lifecycle controller seeds actual host history with recording off for the clear/compact cases, enables only its synthetic project, then issues the host's own local command and a Korean turn. No raw start is manufactured or copied. When `/clear` closes the earlier off-started session after enablement, that different session may have one metadata-only end record; the selected clear session still has exactly four ordered entries. `/new` was observed to produce `startup`, so it is not used as a clear-source substitute. Claude uses its streaming CLI local commands; Unix Codex uses a real pseudo-terminal and `/clear`, `/compact`, `fork` and `/quit`, not injected hook JSON. The Windows terminal commands were entered through the QA terminal and qualified separately.
