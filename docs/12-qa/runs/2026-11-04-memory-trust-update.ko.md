# C1 업데이트 뒤 Codex가 다시 신뢰를 묻는지 확인

[English](2026-11-04-memory-trust-update.md)

TC-107의 관찰 기록입니다.

Windows의 임시 Codex 프로필에서 Codex 0.164.0과 고정 답변을 주는 로컬 모형 서버로 확인한 결과입니다. 아래 업데이트·신뢰 동작의 근거이며 실제 사용자 동의, 실제 모델의 에이전트 걷기, CI 성능, 출시나 태그의 근거로 쓰지 않습니다.

| 단계 | 확인한 결과 |
| --- | --- |
| 이전 소스 `dfc6a2c68d01c840f41206074b6a498cbf06bf27` 설치 | 실제 `plugin add`가 0.1.0을 보고했습니다. Hooks 화면에는 검토 전 비활성 상태의 새 SessionStart 훅 하나가 나타났습니다. |
| 임시 프로필에서 0.1.0 검토·신뢰 | SessionStart가 Installed 1 / Active 0 / Review 1에서 Active 1로 바뀌었습니다. 신뢰 우회 없이 새 `exec`를 실행하니 옛 CORTHEX 맥락이 모형 서버에 전달됐습니다. 옛 0.1.0에는 C1 원문 기록이 없습니다. |
| 같은 로컬 마켓의 MEMORY 소스를 바꾸고 다시 추가 | 실제 `codex plugin add corthex-memory@corthex --json`이 0.2.0을 보고했습니다. 캐시의 제품 파일 45개가 실제 main `2fc4b871873659249e4c43c8b6139c7f5748e186`과 바이트 단위로 같았습니다. |
| 업데이트를 신뢰하기 전에 새 세션 실행 | `exec`는 종료 코드 0이었지만 기억 저장소에 원문과 훅 시간 기록이 각각 0개 추가됐습니다. 훅 신뢰 우회는 쓰지 않았습니다. |
| 실제 대화형 화면 열기 | “Hooks need review”와 새로 생기거나 바뀐 훅 네 개를 보여 줬습니다. SessionStart에는 마지막 신뢰 이후 변경되어 검토가 필요하다고 나왔습니다. |
| 임시 프로필에서 검토한 C1 훅 신뢰 | 설치된 훅들이 활성 상태가 됐습니다. 신뢰한 뒤 TUI를 끝낼 때 글 없는 종료 경계 하나가 기록됐습니다. |
| 신뢰 우회 없이 별도의 한국어 세션 실행 | 실제 CLI 세션에 연결되는 시작·질문·답변·종료가 기록됐고 경계에는 글이 없었습니다. 도구·세션·같은 턴의 한국어·성공 시간 기록·실패 없음도 확인했습니다. 앞선 TUI 종료 한 개를 합쳐 전체 행은 다섯 개입니다. |
| 실제 `memory.py status` 조회 | 종료 코드 0 / done이었고 Codex 네 훅마다 마지막 실행 시각과 ok 결과만 나왔습니다. 내부 1–2개 표본의 시간 요약은 100회 외부 성능 측정의 근거가 아닙니다. |

시험 제어기가 임시 프로필에서 신뢰를 선택했으며 사용자 실제 프로필·저장소에 동의한 것이 아닙니다. 시험용 `on` 동의도 따로 기록했습니다. 가짜 키와 로컬 모형 서버만 사용했고 실제 제공자 호출·계정 로그인·전역 설치는 없었습니다. 호스트 자체의 메타데이터 통신 시도는 차단·기록해 MEMORY의 외부 통신 판정과 구분했습니다.

긴 시험 경로로 관리 daemon의 Windows Unix socket SUN_LEN 제한에 걸려 TUI는 `--no-daemon`으로 실행했습니다. Windows sandbox 설치 창은 닫았으며 관리자·sandbox 설치는 하지 않았습니다. 처음 v1 제어기의 잘못된 demo 재개 경로·daemon 경로 실패·마켓 설정 덮어쓰기는 부적격 근거로 보존했습니다. 적격 v2는 단계마다 기존 설정을 유지합니다.

완료 정본은 `task028-trust-update-v2/complete.json`, SHA256 `e8d255ef3f490c62e13d164eb66a9a08ed2e5776b695f78890af28392018ca26`입니다. 실제 설치·실행·상태 JSON, 도구가 돌려준 TUI 출력과 캐시 소스 확인을 연결했습니다. 제품 소스는 실제 병합한 PR #88입니다. Linux/macOS 업데이트 신뢰 실행과 Git·Notion 사례 판정 승격은 별도이며 이 Windows 결과에서 추정하지 않습니다.
