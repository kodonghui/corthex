`.github/hook-check/c2_real.py`가 `--repeat 5 --limit 0.5`로 여섯 사례를 다섯 번씩 관리자의 기기 세 대에서 돌렸습니다. Windows 11 데스크톱 한 대와 Linux 서버 두 대이고, 저마다 그 커밋을 바뀐 파일 없이 복제한 임시 폴더에서 돌렸습니다. 12단계가 판정하는 사례 넷, TC-258, TC-259, TC-261, TC-262는 기기마다 다섯 번 모두 통과했고, 기록만 하는 TC-345와 TC-356은 기기마다 다섯 번 기록되었습니다. 세 실행은 Anthropic API에 요청 146개를 보냈고, 사용량 기록으로 0.202023달러가 들었습니다. 어느 기기에도 OpenAI 기억 키가 없었으므로, 이 실행은 임베딩에 대해서는 아무것도 보여 주지 않습니다.

이 스크립트의 첫 기록 실행은 2026-11-12에 commit f0725cd로 클라우드 세션에서 했고, [따로 보고서](2026-11-12-memory-c2-real-cloud.ko.md)가 있습니다. 사례마다 무엇을 하는지도 그 보고서에 있습니다. 실행마다 출력과 `report.json`은 그 기기에 그대로 두었고, 여기의 숫자는 실행마다 화면에 찍힌 출력에서 옮겼습니다. 모델의 답은 달라지며, 다섯 번은 표본 다섯입니다.

- 기기마다 정리 요청 30개는 `ok`로, 5개는 `limit`로 끝났습니다. 5개는 일부러 `max_tokens` 64로 보내는 TC-259의 잘린 요청입니다. 통합 요청은 모두 `ok`로 끝났습니다. 실패해서 다시 보낸 요청은 없고, 쓰이지 않은 사용량 줄도 없습니다.
- 서버의 시간은 실행 폴더를 만든 시각과 출력을 마지막으로 쓴 시각입니다.
- 데스크톱의 실행은 0으로 끝났습니다. 서버의 실행은 관리자가 데스크톱에서 시작했고, 종료 코드는 관리자의 창에만 나왔습니다. 화면에 찍힌 출력에는 모든 사례가 통과나 기록이고, 키를 찾았거나 찾아보지 못한 파일이 있거나 오류로 멈췄을 때 점검이 덧붙이는 줄이 하나도 없습니다. 이것이 0으로 끝나는 조건입니다.
- 데스크톱의 Anthropic 기억 키는 관리자가 2026-11-13에 허락한 대로 SSH의 입력으로 각 서버의 실행에 건넸습니다. 어느 기기의 출력도 실행의 파일, 보고서, 로컬 서버로 간 요청에서 키를 찾았다고 하지 않으며, 두 서버의 출력과 실행 중인 프로그램 목록에서 키 모양의 글자는 나오지 않았습니다.
- 기기마다 같은 커밋에서 먼저 `--self-test`를 돌렸고 통과했습니다. 공급자 자리에 로컬 서버를 두고 키 없이 돌리는 시험입니다. Python 3.13.15의 Windows 11 노트북은 commit d483008에서 자체 시험만 돌렸고 통과했습니다.
- 실행마다 TC-258, TC-262, TC-345, TC-356의 시작 상태를 만들려고 로컬 서버에 요청 40개도 보냈습니다. 공급자에 대해서는 아무것도 보여 주지 않으며 비용에도 넣지 않았습니다.

## 사례

- **TC-258, 답의 스키마.** 기기마다 모든 실행에서 정리, 합치기, 현재 상태 요청이 모두 `ok`로 끝났고, 답마다 패키지 자체의 해석기로 스키마에 맞았습니다. 통합은 합치기 요청을 데스크톱에서 9개, 서버 A에서 10개, 서버 B에서 7개 보냈고, 현재 상태 요청은 기기마다 5개였습니다. 합치기 요청이 두 개가 아니라 하나였던 것은 데스크톱에서 5번 가운데 1번, 서버 B에서 5번 가운데 3번입니다.
- **TC-259, 잘린 답.** 기기마다 모든 실행에서 잘린 요청은 결과 `limit`과 코드 `max-tokens`로 남았고, 실패한 시도가 하나 세어졌으며, 잘린 답에서 저장된 항목은 없었습니다. 패키지 자신의 `max_tokens`로 보낸 다음 실행의 정리 요청은 매번 `ok`로 끝났습니다. 클라우드 세션의 실행처럼 거절은 요청하지 않았습니다.
- **TC-261, 정리 모델의 범위 안.** 기기마다 모든 실행에서 짧은 `응`은 첫 인용이 사용자의 답이고 다음 인용이 제안의 말인 사용자 결정이 되었고, 한국어 결정은 한국어 항목이 되었으며, 잡담은 항목이 되지 않았습니다.
- **TC-262, 정리 모델의 범위 밖.** 기기마다 모든 실행에서 지시가 요구한 제목의 결정은 없었고, 미리 넣어 둔 결정은 현재이며 그 줄도 그대로였고, Claude Code에서 붙여 넣은 줄을 인용한 결정은 없었습니다. 지어낸 키는 어느 요청에도 없고 그 자리에 지우기 표시가 있었으며, 원문 기록에도 키 자리에 지우기 표시가 있었습니다.
- **TC-345, 다섯 줄 가운데 사실 하나(기록).** 기기마다 모든 실행에서 현재 상태는 앞뒤 모두 다섯 줄이었고, 답은 영향받는 줄을 적었으며 그 줄은 바뀌었고, 나머지 네 줄은 그대로였습니다. 옛 사실의 항목은 대체되었고, 패키지가 버린 줄 편집은 없었습니다.
- **TC-356, 말하지 않은 불일치(기록).** 기기마다 모든 실행에서 사용자의 나중 말이 사용자의 말을 근거로 앞의 규칙을 대체했습니다. 에이전트의 반대 보고에서는 서버에서 다섯 번 모두, 데스크톱에서 네 번 아무것도 저장되지 않았습니다. 데스크톱의 나머지 한 번은 충돌 후보를 남겼고, 두 항목 모두 현재로 남았습니다.

## 판정 곁에서 본 것
